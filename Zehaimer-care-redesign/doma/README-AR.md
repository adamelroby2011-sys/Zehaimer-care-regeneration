# Zehaimer-care — نسخة بتصميم موحّد

## محتويات المجلد
- `index.html`: صفحة تسجيل الدخول التي تظهر عند فتح رابط GitHub Pages.
- `login/style.css` و`login/main.js`: تصميم وسلوك صفحة الدخول.
- `main page/main.html`: لوحة البيانات الرئيسية.
- `main page/style.css` و`main page/main.js`: تصميم لوحة البيانات وأزرار Bluetooth وWi-Fi.
- `contact us/contact.html` و`contact us/style.css`: صفحة التواصل بتصميم البطاقات.
- `contact us/images/mostafa-elramah.jpg`: صورة مصطفى المستخدمة في صفحة التواصل.
- `moment-of-pride.html`: صفحة بطاقة التهنئة التي كانت ضمن الملفات المرسلة.

## طريقة الرفع
1. خذ نسخة احتياطية من مستودعك الحالي أولًا.
2. ارفع محتويات هذا المجلد إلى جذر مستودع `Zehaimer-care` مع الحفاظ على أسماء المجلدات والمسافات كما هي.
3. من `Settings → Pages` اختر `Deploy from a branch` ثم الفرع `main` والمجلد `/(root)`.
4. بعد انتهاء النشر، افتح الموقع واضغط `Ctrl+F5` لتجاوز نسخة المتصفح المخزنة.

## ملاحظات مهمة
- روابط `Contact Us` ومسارات CSS/JavaScript متوافقة مع بنية المجلدات في هذه الحزمة.
- بيانات GPS والنبض والضغط والسكر أرقام تجريبية وليست قراءة أجهزة حقيقية؛ يلزم ربط حساسات وكتابة تكامل فعلي لتحديثها.
- صفحة الدخول الحالية للتجربة فقط: بيانات التحقق في JavaScript ويمكن لأي شخص يفتح أدوات المطور رؤية منطقها. لا تستخدمها لحماية بيانات حقيقية. يلزم نظام تسجيل دخول من جهة الخادم أو مزوّد مصادقة موثوق لذلك.
- رابط صورة بطاقة التهنئة الخارجية يحتاج اتصالًا بالإنترنت حتى تظهر الصورة.
